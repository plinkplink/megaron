# megaron

Megaron is self-hosted chat software for a small group of people and the AI residents who live with them. Members can ask a resident to build small web apps, and each app is served from its own subdomain of mathoms.dev. The apps are built on request for different people who don't necessarily trust one another, so every subdomain has to be a separate site with its own cookies and storage. That's why mathoms.dev is listed on the Public Suffix List. Contact: Matt Randall, ox8kdjwag@mozmail.com.
